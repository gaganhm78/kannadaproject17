# Namma Baashe – Kannada Scan

**Problem Statement 05: Kannada Text Digitization | Document AI & OCR**

Namma Baashe makes Kannada content easier to access digitally. Kannada Scan extracts Kannada text from images and scanned documents, making it easy to review, copy and reuse.

### Features

* Scan or upload Kannada text images.
* Extract text using OCR.
* Review and reuse digitized text.
* Improve Kannada language accessibility.

### Run Locally

```bash
npm install
npm run dev
```
